# Verifying LHC results with iSpy WebGL and CMS Open Data

Survey of the tools and data in [cms-outreach/ispy-webgl](https://github.com/cms-outreach/ispy-webgl)
(commit `7a90070`, 13 Mar 2026, v2.0.0-rc), what the bundled event files actually contain,
how far they can be used to check published LHC results, and a cross-reference to the
open literature from the 2012 Higgs discovery onward.

Everything in `results/` is regenerated by `tools/run_all.sh` (clones the two public
repositories, needs `python3` and `pip install uproot`).

## 1. What the repository is

iSpy WebGL is a browser event display for CMS built on three.js. It is a *viewer*, not an
analysis framework: it draws reconstructed objects stored in `.ig` files and offers a
few interactive calculations. Published description: T. McCauley, *J. Phys.: Conf. Ser.*
898 (2017) 072030, doi:10.1088/1742-6596/898/7/072030; software DOI 10.5281/zenodo.8043417.

| Folder | Content | Notes |
|---|---|---|
| `js/` (16 files, ~270 kB) | Application code (ES modules, Vite build) | `objects-config.js` declares 130 collection types the display understands (tracker, calorimeter, muon system, PF/PAT physics objects, HGCal, GEM, forward protons); `objects-draw.js` renders them; `display.js` holds the invariant-mass calculator |
| `data/` (9 `.ig` files, 23 MB) | Bundled sample events | See section 2 |
| `geometry/gltf` (50 `.glb`), `geometry/json` (13), `geometry/obj` (2) | CMS detector geometry | Used only for drawing |
| `index.html`, `css/`, `fonts/`, `graphics/` | UI | Bootstrap 5, dat.gui |
| `.gitlab-ci.yml` | Deploys to CERN WebEOS (`cern.ch/ispy-webgl`) | |

Analysis-relevant features found in the code:

* **Invariant mass of selected leptons** (`js/display.js:370-536`): the user clicks
  electrons/muons in the 3D view and presses `M`; the app sums four-vectors built from
  `pt, eta, phi` with m_mu = 105.66 MeV and m_e = 0.511 MeV and shows sqrt(E^2 - p^2).
  No charge, isolation, or flavour check is applied; the README itself says to treat the
  number as guidance only.
* **Cuts in the tree view**: a `min_pt`/`min_et` threshold per collection (tracks, jets,
  muons, electrons, photons).
* **Object table**: raw values of every stored field per object, hover-linked to the 3D
  view.
* **Console access**: `ispy.current_event.Collections[...]` exposes the parsed JSON, so
  any calculation can be done in the browser devtools.

The companion [cms-outreach/ispy-analyzers](https://github.com/cms-outreach/ispy-analyzers)
package (last commit 7 Mar 2022) is the producer: a set of CMSSW `EDAnalyzer`s
(`src/ISpy*.cc`, 70 analyzers) plus a `ISpyService` that writes one JSON document per
event into a zip archive (`.ig`). Configurations exist for CMSSW 2_X through 10_X,
7 and 8 TeV, Run 2 AOD and miniAOD, cosmics and splash events. Producing new `.ig`
files from CMS Open Data therefore requires the CMS Open Data CMSSW container or VM
plus this package.

## 2. The "database": the bundled `.ig` files

An `.ig` file is a zip archive, one member per event (`Events/Run_<run>/Event_<event>`),
each a JSON document with `Types` (schema), `Collections` (rows) and `Associations`.
The JSON is non-standard (parentheses for vectors, single quotes, bare `nan`); the
display repairs it in `js/files-load.js:474-477` and `tools/iglib.py` does the same.

The nine files hold **211 events of real 2012 proton-proton collisions at 8 TeV**,
taken from the CMS "22Jan2013" legacy re-reconstruction that CERN Open Data released in
2017. Every `.ig` carries the full list of CMSSW products used (`Products_V1`): reduced
ECAL/HCAL rec-hits, `recoMuons:muons`, `recoGsfElectrons`, `recoPhotons:photons`,
`ak7PFJets`, `pfMet`, `hpsPFTauProducer`, `offlinePrimaryVertices`, `generalTracks`,
HLT `TriggerResults` and `hltTriggerSummaryAOD`.

Record numbers without a DOI above were confirmed only through search-engine snippets;
the remaining five datasets (BJetPlusX, DoublePhoton, MET, MinimumBias, TauParked) are
certainly in the same December 2017 release (CERN Open Data GitHub issue
cernopendata/opendata.cern.ch#1404 lists event-display files for all 26 Run2012B/C
primary datasets) but their record IDs were not verified because opendata.cern.ch is
unreachable from this environment.

Each per-dataset file is simply the first 25 events of one AOD file
(`outputMaxEvents = 25` in `ispy-analyzers/python/ispy_AOD.py`), i.e. a single
lumisection with no physics selection beyond the dataset trigger. Full per-event
listing: `results/ig_inventory.txt`.

**Data-quality check.** All 211 events fall inside the CMS validated-run list
`Cert_190456-208686_8TeV_22Jan2013ReReco_Collisions12_JSON.txt` that CERN Open Data
requires for 2012 analyses (`results/cert_check.txt`, 0 uncertified events).

**Caveats stated by the authors and confirmed in the code.** Jets are `ak7PFJets` with no
pT cut (40-60 jets per event, mostly pile-up); photon `et` and electron `pt` carry no
energy-scale corrections; muons are `recoMuons` global muons without the Rochester-type
corrections used in the papers. Masses computed from these objects are therefore
expected to agree with published values only to a few percent.

## 3. Verification against published results

### 3.1 The Higgs boson in H -> ZZ* -> 4l (the strongest check)

`Hto4l_120-130GeV.ig` contains 11 real data events, each with four isolated leptons
whose invariant mass lies in the 120-130 GeV window. `tools/h4l_check.py` re-derives the
kinematics using the CMS pairing rule (Z1 = opposite-sign same-flavour pair closest to
m_Z, Z2 = remaining pair with highest pT sum):

| Run | Event | Channel | m(Z1) | m(Z2) | m(4l) [GeV] |
|---|---|---|---|---|---|
| 195099 | 137440354 | 2e2mu | 75.8 | 29.2 | 126.7 |
| 198213 | 27000461 | 2e2mu | 67.7 | 39.0 | 121.5 |
| 199319 | 1203594102 | 4mu | 58.4 | 45.7 | 125.6 |
| 200091 | 1605749984 | 2e2mu | 92.2 | 34.3 | 129.9 |
| 200466 | 153791279 | 2e2mu | 90.3 | 34.8 | 126.5 |
| 201174 | 216745941 | 2e2mu | 86.9 | 19.9 | 124.9 |
| 201191 | 1357605031 | 2e2mu | 80.8 | 14.5 | 128.6 |
| 201707 | 635670564 | 4mu | 88.4 | 25.0 | 122.4 |
| 201707 | 805047482 | 4e | 74.2 | 14.0 | 125.4 |
| 202178 | 1430970868 | 4mu | 77.4 | 24.6 | 122.5 |
| 202299 | 421267699 | 4e | 93.7 | 28.7 | 125.2 |

Observations:

* The topology is the published one: one on-shell or near-on-shell Z plus one far
  off-shell Z*, exactly the H -> ZZ* signature (m_H < 2 m_Z).
* The **sample is precisely the set of 2012 open-data candidates found by the CERN Open
  Data H -> 4l example analysis** (Jomhari, Geiser, Bin Anuar 2017, CERN Open Data record
  5500, DOI 10.7483/OPENDATA.CMS.JKB8.RR42; GitHub mirror
  `cms-opendata-analyses/HiggsExample20112012`). That analysis ships its 2012 data
  histograms (`rootfiles/DoubleMu12.root`, `DoubleE12.root`, 3 GeV bins). In the 120-130
  GeV window those histograms contain 3 events in 4mu, 6 in 2mu2e and 2 in 4e, and the
  `.ig` file contains 3 / 6 / 2 events whose recomputed masses land in **exactly the same
  bins, channel by channel** (`results/opendata_h4l_compare.txt`). The display sample
  and the published open-data re-analysis are therefore the same 11 events.
* With 11 events the mean of m(4l) is 125.4 GeV (sample spread 2.6 GeV, i.e. about
  0.8 GeV on the mean). This agrees with the 2012 CMS discovery value in this channel
  and with the current world average (section 4), although with uncorrected lepton
  momenta it should be read as a consistency check, not a measurement.
* The open-data example reports an excess of about 2 standard deviations on this 50 %
  public subset, versus 3.2 sigma in the 4l channel of the discovery paper; the bundled
  file is the excess, not the background. The example's own 4l spectrum has 82 events
  between 70 and 181 GeV with a Z -> 4l peak at 88-94 GeV and a ZZ continuum above
  180 GeV, as in Fig. 4 of the discovery paper.

### 3.2 Z boson in dielectron and dimuon data

Among the 200 untargeted events, the leading opposite-sign same-flavour pairs give seven
Z candidates: 90.8, 92.4, 93.3, 86.5 GeV (ee, DoubleElectron), 87.1 GeV
(ee, DoublePhoton) and 93.9, 88.1 GeV (mumu, DoubleMuParked). Their mean is 90.3 GeV
with a scatter of 3 GeV, consistent with m_Z = 91.188 GeV and with the 2-3 GeV
detector resolution before calibration. The open-data DoubleMuParked 2012 dimuon
histogram (`demo/massZto2muon`, 6.2 million entries) peaks in the 91.0 GeV bin.

### 3.3 Quarkonia in the dimuon spectrum

One DoubleMuParked event (run 199318, event 119833617) has an opposite-sign dimuon at
3.08 GeV, consistent with the J/psi (3.097 GeV). The full open-data 2012 dimuon
spectrum (`demo/GMmass_extended`, 32.8 million entries, 0.5 GeV bins) shows local
maxima at 3.25 (J/psi, psi'), 9.25 and 10.25 (Upsilon 1S/2S/3S) and 90.75 GeV (Z),
reproducing the textbook CMS dimuon spectrum that CERN Open Data publishes as record
12342.

### 3.4 What the other files can and cannot show

| File | Usable for | Not usable for |
|---|---|---|
| DoublePhoton | Visual examples of two-photon events; diphoton masses 64-153 GeV with uncorrected ET; one event at 121.1 GeV (run 194115, event 652001849) is in the H -> gamma gamma window but is one event in a continuum of ~10^5 | Any statement about the 125 GeV diphoton peak (needs ~10^4 events and the full photon calibration) |
| JetHT, BJetPlusX | Multijet topologies, dijet masses, b-jet-like displaced structure visible in tracks/vertices | Dijet resonance or QCD cross-section checks (25 events, no JEC) |
| MET | Events with PF MET up to 124 GeV; shows what a "real" MET event looks like | SUSY / dark-matter limits (no selection, no MC) |
| TauParked | Hadronic tau candidates (`hpsPFTauProducer`) | H -> tau tau (needs MC and tau ID working points) |
| MinimumBias | Soft collisions, pile-up vertices (`Vertices_V1`) | Luminosity, underlying-event measurements |

### 3.5 Limits of what can be "verified" with this repository

1. 25 events per dataset is a visual sample, not a statistical one. Any published
   measurement requires the full AOD/NanoAOD datasets from opendata.cern.ch (the 2012
   DoubleMuParked AOD alone is 36.8 million events, 9.8 TiB) processed with CMSSW or
   the NanoAOD + ROOT/uproot/coffea tool-chain.
2. The display applies no calibrations, identification or isolation; reproduced masses
   are at the few-percent level.
3. Only 2011-2012 (Run 1) and a 50 % share of each year are public; the Run 2 results
   quoted in section 4 use 20-60 times more luminosity than what is in the open data.

### 3.6 Beyond the display: the full public 2012 sample (`tier2/`)

The two statistical tests that the public NanoAOD files support were run; details and
tables in `tier2/README.md` section 4, outputs in `results/tier2/`.

* **Dimuon spectrum**, 24.1 million opposite-sign pairs: J/psi, psi(2S) and the three
  Upsilon states at their PDG masses to 0.12-0.15 % (34 MeV and 101 MeV resolution), the
  Z 0.3-0.5 % low (uncorrected momentum scale plus unrecovered final-state radiation),
  1.2-1.6 GeV resolution. Every published resonance in the CMS dimuon spectrum is
  reproduced.
* **H -> ZZ* -> 4l**, 11.6 fb^-1: 10 data events in 120-130 GeV against 3.06 expected
  ZZ background and 5.51 expected SM Higgs events, a 3.0 sigma counting excess; the
  Z -> 4l control region agrees (32 vs 27.9). Nine of the ten are the display's events
  with identical masses; the two display events lost and the one gained are explained by
  the absence of lepton identification in the NanoAOD skim.
* The display file itself is byte-identical (md5) to CERN Open Data record 5200, whose
  candidate lists contain all 11 events with official masses within 0.5 GeV of the
  recomputed ones (`results/record5200_compare.txt`).

## 4. Cross-reference to the open literature since the Higgs discovery

Facts below were gathered by web search; arXiv, Nature and opendata.cern.ch could not be
fetched directly from this environment. Items that rest on memory rather than a fetched
source are marked *(unverified)*.

### 4.1 Higgs mass: what the 11 events should be compared with

| Measurement | m_H [GeV] | Reference |

| CMS H->4l, full Run 1 | 125.6 +- 0.4 +- 0.2 (6.8 sigma; signal window 121.5-130.5 GeV) | PRD 89 (2014) 092007, arXiv:1312.5353 |

The 11 display events (mean 125.4 GeV, about 0.8 GeV statistical uncertainty on the mean,
no calibration) are compatible with every entry. The file's 120-130 GeV window is the
Run 1 CMS convention (121.5-130.5 GeV). The channel split (3 four-muon, 6 two-muon-
two-electron, 2 four-electron) follows the expected relative yields: CMS quoted
2.75 : 3.44 : 1.37 expected signal events (4mu : 2e2mu : 4e) for m_H = 125 GeV in
110-160 GeV on 2011-2012 data (arXiv:1303.4571), and the open-data subset is 50 % of
Run 1. SM branching fraction H -> ZZ* -> 4l (l = e, mu) is 1.24e-4 (ATLAS Open Data
documentation), which is why only ~11 clean candidates exist in 10 fb^-1 of 2012 data.

### 4.2 Open-data reproductions of the 4l result

* **Record 5500**, Jomhari, Geiser, Bin Anuar (2017), DOI 10.7483/OPENDATA.CMS.JKB8.RR42,
  code `cms-opendata-analyses/HiggsExample20112012` (CMSSW_5_3_32). Excess of about
  2 sigma on the public 50 % of Run 1 versus 3.2 sigma in the 4l channel of the
  discovery paper. Section 3.1 shows the display sample is this analysis's 2012 signal
  region, event for event.
* **Record 5200**: `HiggsCandidates/4lepton.ig` and `diphoton.ig`, "Higgs candidate
  events from CMS 2011 and 2012 open data release selected in the H->4l example". This
  is almost certainly where `Hto4l_120-130GeV.ig` was taken from (commit "new data from
  web in file load", 10 Oct 2019); the repository itself does not document the origin.
* **Record 12360**, S. Wunsch (2021), the same analysis in ROOT RDataFrame on NanoAOD,
  DOI 10.7483/OPENDATA.CMS.F7HD.P3K4; REANA workflow `reanahub/reana-demo-cms-h4l`.
* **Record 12342 / 12341**: 2012 DoubleMuParked muon NanoAOD (61.5 M events) and the
  dimuon-spectrum example reproduced in section 3.3; the ROOT tutorial
  `df102_NanoAODDimuonAnalysis` runs on the same file.
* An H -> gamma gamma open-data example exists for the 2011 Photon and 2012
  DoublePhoton datasets (`cms-opendata-analyses/2011-photon-2012-doublephoton-higgs-hgaga`);
  it is the right next step for the `DoublePhoton` file but needs the full dataset.
* No peer-reviewed journal paper re-deriving the 4l peak from CMS open data was found;
  the reproductions live on the portal and GitHub. A 2026 preprint (arXiv:2603.20179)
  reports autonomous agent reproduction of a CMS Run 1 open-data H -> tau tau result.

### 4.4 Other post-2012 LHC results relevant to the bundled datasets

* **Z and quarkonia** (DoubleMuParked, DoubleElectron): the Z candidates in section 3.2
  and the J/psi candidate in section 3.3 are the only resonances visible in 25-event
  samples; the full 2012 dimuon spectrum (record 12342) shows eta, rho/omega, phi, J/psi,
  psi', Upsilon(1S,2S,3S) and Z. The 30 GeV bump in that spectrum is a trigger
  threshold effect, not a resonance.
* **Bs -> mu mu**: CMS + LHCb combined observation, Nature 522 (2015) 68, branching
  fraction (2.8 +0.7 -0.6) x 10^-9, > 6 sigma, on 2011-2012 data. The DoubleMuParked
  stream contains the relevant low-mass dimuon triggers, but the signal is a few dozen
  events in 25 fb^-1.
* **Diphoton resonances** (DoublePhoton): the CMS 8 TeV search covered 150-850 GeV
  with no excess (PLB 750 (2015) 494, arXiv:1506.02301). The 750 GeV excess of
  December 2015 (ATLAS local 3.9 sigma, CMS 2.6 sigma) disappeared with 2016 data
  (CMS PLB 767 (2017) 147, arXiv:1609.02507; ATLAS JHEP 09 (2016) 001). The bundled
  diphoton masses go up to 553 GeV (JetHT file), all consistent with the continuum.
* **Jets + MET searches** (JetHT, MET, BJetPlusX): CMS 8 TeV monojet (EPJC 75 (2015)
  235) found nothing; full Run 2 limits push gluinos above 2.0-2.3 TeV (CMS
  arXiv:1908.04722; ATLAS JHEP 02 (2021) 143) and give the most restrictive
  mediator limits (CMS monojet arXiv:2107.13021). The MET file's largest event has
  124 GeV of PF MET, far below any search threshold.
* **Top and W masses** (dilepton + jets + MET): ATLAS + CMS Run 1 top-mass combination
  172.52 +- 0.33 GeV (PRL 132 (2024) 261902); first 13.6 TeV ttbar cross section
  881 +- 30 pb (CMS arXiv:2303.10680). CMS W mass 80360.2 +- 9.9 MeV (Nature 652
  (2026) 321, arXiv:2412.13872), consistent with the SM and with ATLAS, not with CDF
  (80433.5 +- 9.4 MeV).
* **LHCb exotics**: pentaquarks Pc(4380), Pc(4450) (2015, arXiv:1507.03414) and
  Pc(4312), Pc(4440), Pc(4457) (2019, arXiv:1904.03947); T_cc+ (arXiv:2109.01038);
  X(6900) in di-J/psi (arXiv:2006.16957), confirmed by ATLAS and CMS (PRL 131 (2023)
  151902; PRL 132 (2024) 111901). None are reachable with CMS 2012 open data at this
  sample size.

## 5. Bottom line

* iSpy WebGL is a viewer with one physics calculation (lepton invariant mass). Its
  bundled "database" is 211 certified 2012 collision events, 200 of them unselected,
  plus the 11 H -> 4l candidates that the CERN Open Data H -> 4l example found.
* Those 11 events reproduce the published topology and mass (mean 125.4 GeV) and match
  the open-data re-analysis bin for bin; the Z and J/psi show up where they should.
* Nothing else in the repository constitutes a statistical test of a published result.
  With the full public 2012 NanoAOD files (section 3.6) the dimuon resonances and the
  4l Higgs excess are reproduced as statistical tests; H -> gamma gamma, Bs -> mu mu,
  top, W and exotics would need the AOD datasets and the CMSSW tool-chain.
